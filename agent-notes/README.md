# Agent notes scaffold

This directory is a project-local place for durable observations that need owner direction or a documented exception. It starts empty: copied standards do not bring project records with them.

## Note registry

Use [`note-registry.md`](note-registry.md) as the single index. Record only actionable, evidence-backed observations and keep each entry linked to the relevant project files. Remove or close entries when their disposition is recorded.

## Porting this scaffold

Keep the registry format and headings. Replace this guidance only if the consuming project has an explicit owner-approved note workflow. Do not copy sample project-specific facts into a new project.

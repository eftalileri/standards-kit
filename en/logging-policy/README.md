## Agent TL;DR

- Select and document one maintained backend logging implementation and a runtime-compatible output format (single-line JSON where the hosting platform collects stdout/stderr). Error logs **MUST** include the context required by the shared error policy. Every level's structured metadata passes the shared bounded credential scrubber before all transports; opaque cursor/continuation values are redacted; error message/stack/cause text stays visible and is value-scanned for live credentials only — never deleted by field name or replaced by a fixed "detail redacted" sentence — and the process-level crash writer applies the same scan (**M23**/**M25**/**M26**/**N9**/**N10**, **SEC-LOG**). One writer per process crash (**M15** process-boundary note).
- Log a failure once, at the boundary (**M15**); inner re-log on a path with a downstream boundary is forbidden (**N7**). Level by category: `OPERATIONAL` / `BUSINESS` → `warn`, `SYSTEM` → `error` (**M16**) — classification, not demotion.
- `error` → crash reporting; expected `warn` → metric channel only, never crash reporting (**M17**, **M18**, **N6**). Same `traceId` in log + response + crash report (**M19**).
- Durable inbox/outbox workers log once per attempt at the outer boundary with safe event id, attempt count, and resulting durable state; terminal exhaustion stays visible, raw provider payloads and replayable credentials stay out (**M24**).
- Request correlation accepts only one canonical UUID header value or generates a fresh server UUID; rejected raw values never egress (**M27**). One production access/latency authority uses the **M28** normalized/bounded SLO field allowlist plus fixed diagnostic literals, never raw URL/query/body/headers/identity/client text (**M28**).
- Where a runtime requires preloaded instrumentation, it initializes before the application entry; the package start is the launch authority and every supported launcher preserves the same ordering (**M29**, **N13**).
- The raw-error-text rules are bounded by a type-annotation proof that a binding carries a throwable — not by the `catch`/handler scope it sits in, and never by a variable name or the top type; one shared predicate authority answers that question for every rule (**M32**).

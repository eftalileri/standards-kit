# Orthographic corruption — the shapes a catalog check **must** be cut by

**Keywords:** ASCII-ization, transliteration, diacritic, digraph, elision, apostrophe, corpus dominance, ratchet baseline, spelling corruption

Scope

- Included: A catalog value whose text is in the right language and carries the right meaning, but whose spelling has been mechanically damaged — a letter's mark stripped, a letter expanded into an ASCII pair, a word-joining punctuation mark dropped. How a check for that damage is scoped, what evidence may decide "this word is misspelled" without a dictionary, and what a check of this class owes when it cannot see part of the class.
- Excluded: A missing or empty key, and placeholder parity across languages ([user-text-catalogs-and-parity.md](user-text-catalogs-and-parity.md), **I18N-CAT-M4**). A value that is the wrong word or a mistranslation — the per-language terminology limit stated in [internationalization-rn.md](internationalization-rn.md) governs, and no check in this band decides it. Which characters a language is entitled to ([markdown-authoring-deliverable-shape.md](../authoring/markdown-authoring-deliverable-shape.md), KV2–KV3) — that prohibition is the obligation this band's checks measure, not a rule this band restates. The design vocabulary of a ratchet itself ([check-design-rules.md](../false-positive/check-design-rules.md), **FP-M18**).
- Document type: Normative part — **I18N-CAT-M7**.

## **MUST**

| ID | Rule |
|----|------|
| **I18N-CAT-M7** | A check that audits catalog spelling **MUST** be scoped by the TRANSFORMATION that produces the corruption, and **MUST** carry one arm per transformation shape it claims. "ASCII-ization" is not one defect; it is a family of edits that damage a word in structurally different ways, and a predicate built for one shape is blind to the others by construction, not by oversight. Three shapes are measured and distinct: (i) mark stripping, where a combining mark is removed and the word keeps its length; (ii) digraph expansion, where a letter becomes an ASCII pair and the word gets longer; (iii) elision dropping, where a word-joining punctuation mark is replaced by a space and no letter changes at all. A frequency predicate keyed on folded letters sees only (i): (ii) folds to a different key, and (iii) changes no key it counts. (a) The blindness is not repaired by widening the existing arm's tolerance; it is repaired by adding the arm. Loosening a shared threshold to reach a shape the predicate cannot represent buys the missing shape with false positives on the shape it already read correctly, which is a trade down, not a fix. Each arm therefore carries its own baseline and ceiling ([**FP-M18**](../false-positive/check-design-rules.md)(b)(c)); sharing one counter across arms lets a closure in one shape pay for new debt in another, which is exactly the silence the ratchet exists to prevent. (b) The evidence that a word is misspelled **MUST** come from the same language's own catalog corpus, never from a transformation table alone. A table says only that a sequence *could* be a corruption; every one of these transformations has a large legitimate co-domain in its own language, and blind conversion manufactures new defects in correct text. The admissible predicate is corpus dominance: reverse the transformation, and report the value only when the reversed form is attested in that language's own catalogs and dominant over the bare form by the arm's ratio. This is dictionary-free, it is per-language without a per-language word list, and it is self-healing — once a value is repaired the corrected form enters the corpus, so the same corruption is caught the next time it appears. (c) A corrected value's spelling **MUST** be taken from that same corpus, never composed. Where the corpus does not attest the corrected form, morphological evidence *from that corpus* — an attested prefix, an attested suffix class, an attested inflection of the same stem — may decide it, and where neither exists the value is left alone and recorded as unclosed. Writing a plausible-looking accent is worse than leaving the value bare: a bare word reads as an omission, an incorrectly accented one reads as the language's own spelling and no reader reports it. (d) The part the check cannot see is written into the check's own source, with its measurement and the information a closing predicate would need. A blind spot named in the source is a declared limit; the same blind spot unnamed reads as coverage, and every later reader of a green run infers a cleanliness that was never measured.  |
| **I18N-CAT-M7** (cont.) | (e) A language is placed in or out of the check's scope by MEASUREMENT of its own corpus, never by its script or alphabet family, and every exclusion is re-measured by the check on every run. Script is not the discriminator; the discriminator is whether the language has an orthographically mandatory mark that a precomposed character carries. A scope note reading "this class does not exist in these languages" is a claim about data, so it is verified like one: the check counts the mark-bearing forms in each excluded catalog and fails when the count stops being zero, naming the language and telling the reader to govern it. A hand-maintained exclusion list that nothing re-measures is strictly worse than an undeclared gap, because it hands every later reader a false assurance in place of an unanswered question — the failure (d) forbids, in its most durable form. For the same reason the check **MUST** also fail on a language present in the tree that is in neither set, so adding a locale cannot silently widen the blind spot. (f) Within one language, a mandatory mark **MUST** be separated from an optional one, and only the mandatory mark's absence is a defect. Many scripts write both: a mark whose omission misspells the word, and a mark whose omission is ordinary orthography. Folding them together makes correct text report and buries the real defects among the noise. The separation is available without a per-language table, because the two classes differ in how the source encodes them: a mandatory mark is normally carried by a precomposed character and appears only as a product of canonical decomposition, while an optional mark is typed as a standalone combining code point. A predicate that folds only decomposition-derived marks — leaving standalone marks intact — therefore separates the classes in every script at once, derived from Unicode itself rather than from a hand-written list ([**FP-M33**](../false-positive/check-verification-rules.md) — scope derives from the artifact's own shape). (g) A language whose class exists but whose corpus measures clean is governed at a zero baseline, not excluded. Cleanliness is a fact about today's data; the class's existence is a fact about the language, and excluding on today's count converts a passing measurement into a permanent blind spot.  |

## The same corruption outside the catalog — text a screen composes at render time

A catalog audit is structurally blind to a value the catalog never held. Numbers, dates and times are not translated; they are *formatted*, at render time, from data — so none of the arms above can reach them, and the corruption they produce is the one this family exists to prevent: a reader of a non-Latin numeral system sees the amount in their own digits and, on the same line, the date in Latin ones. The obligation therefore sits at the production point, and it has two halves.

(1) No user-facing date, time or number is produced without the locale being passed. A locale-aware formatter called with no locale argument — or with `undefined`, which enters the engine by the same door — falls back to the device's language, not the application's. The failure is silent in the worst way: it raises nothing, returns no empty value, and looks correct to every reviewer whose device language happens to match. A fixed locale is not forbidden; a *machine* value (a grouping key, a query key, an offset derivation) is deliberately pinned and the user's language **must not** be let in. What is forbidden is passing nothing. A non-integer number handed raw to a translation sentence is the same defect: the engine prints it with `String(value)`, so every language reads `2.4`; it is formatted first, through the product's one decimal display authority, and the sentence receives text (this shape is held by review — a single-file call-argument check cannot see it).

(2) No such value is assembled by string concatenation. Splitting a date and re-joining it — `${d}.${m}.${y}` — pins the numeral system to whatever the source string carried, usually Latin, and no locale can reach it afterwards. This shape survives review precisely because it *looks* deliberate. The reverse is the same defect: a sentence that needs the date and the time as separate placeholders **must** format each with its own formatter call, never cut one combined date-time string at a separator — each locale puts its own comma, ordering and day-period marker there, so the cut leaves residue or swaps halves. Review-held.

(3) A list of user-visible names — and the segments of a composed screen-reader name — is joined only through the product's one list-formatting authority, never with a literal `", "`: Japanese and Chinese enumerate with `、`, Arabic with `، `, so a literal Latin separator is a foreign mark in exactly the languages nobody on the team reads. A server producer that does not know its reader's language (a report row read by both PDF and preview, a list built inside a transaction) **MUST** carry the names as parts and join them at the display edge in that edge's language; a wire field a released client renders verbatim keeps its string shape and is joined at the API edge in the requesting user's language, because a pre-joined string has already chosen one separator for every reader. *(No check is claimed: a literal join is undecidable between user text and diagnostic text within one file — **ENA-A1**(d); review-held.)*

(4) Two user-visible parts — a label and its value, an action and its target, an item and its detail, or a label with its trailing colon — MUST be joined only through the product's one display-pair authority (catalog format keys), never with a literal `": "`, `" - "` or `" – "`: the colon, dash and the spacing around them are language data (French spaces before the colon, Japanese and Chinese use full-width marks). *(No check is claimed, on the same ground as (3) — **ENA-A1**(d); review-held.)*

Stated enforcement limit ([**KIT-INV-8**](../authoring/kit-structural-invariants.md)(b)): only half of this is mechanically decidable. Half (1) is a single-file syntax-tree question — "does this call carry a first argument?" — and can be checked in one file. Half (2) is not: a template literal carries no marker saying its fragments are a date, and a predicate wide enough to catch it would report every `${a}.${b}` in the tree. Closing it would need a way to know a template's *meaning*, which no syntax tree holds; until then half (2) is prose here and is caught in review.

## Stated enforcement limit — a corrected form the corpus has never carried

Corpus dominance can only see a corruption whose repaired form the language has already written somewhere. That is the price of being dictionary-free, and it is a real gap, not a theoretical one: a corrupted value is invisible to the predicate when the repaired word has never appeared in that language's catalogs at all, or when the repaired form is attested exactly as often as the corrupted one and so cannot clear the dominance ratio. Such values are found by reading the corpus for the shape rather than by the check, and repaired from morphological evidence in that same corpus under **I18N-CAT-M7**(c).

Why the gap narrows on its own, and where it does not. Each repair puts the correct form into the corpus, so the same word can never be corrupted invisibly a second time; the class that stays open is a word whose correct spelling has never been used in that language — a first occurrence, which is also the case where a reviewer has the least context to judge it. The dominance ratio is the second half of the limit: lowering it to reach the equally-attested case is a trade the adopting project should measure before accepting, because at a lower ratio legitimate minimal pairs in several languages can begin to report, and a check that cries wolf on correct text is retired by its readers rather than obeyed.

What a check would need in order to close it. A per-language lexicon, or an authority that can decide the spelling of a word the project has not written before — neither of which a source tree contains, and neither of which is derivable from the catalogs themselves. Until such an authority is available, this paragraph is the statement that the first-occurrence half of the class is carried by review, not by a gate; the recurrence half is gated.

A fourth shape sits outside every arm: script substitution. A value written wholly in another alphabet (Cyrillic typed as Latin transliteration) changes no mark, letter count or punctuation, so no arm counts it. Its one dictionary-free tell is a user-visible value with no letter of its own script; that list is review candidates, not a gate, since brand names, URLs and tokens legitimately have none. Repair is an evidence task (KV2(c), **I18N-CAT-M7**(c)). *(No check is claimed: the shape is rare and a recurrence has not been demonstrated — **ENA-A1** (a); review-held.)*
